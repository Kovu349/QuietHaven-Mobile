# 🏠 QuietHaven

QuietHaven is a mobile app designed to help students discover calm, study-friendly locations nearby.

The idea is simple:

**Find a place. Focus. Get things done.**

Instead of overwhelming users with endless options, QuietHaven provides carefully selected study locations with useful information like amenities, official websites, and directions.

# 🧹 Design Decisions

QuietHaven focuses on useful features instead of adding features just because other apps have them.

## Removed Saved Tab

Originally:

```
Home
Explore
Saved
More
```

After reviewing the user experience:

- The app has a curated list of locations
- Filters already organize locations
- Saved locations added unnecessary complexity

The Saved tab was removed to keep the app cleaner and easier to navigate.
